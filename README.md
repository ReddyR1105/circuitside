# CircuitSide

CircuitSide is a planned Android app for organizing Formula 1 race-weekend trips. It is the undergraduate CSC 4360 Mobile App Development capstone for the TropicaGuide Travel Planner topic.

Travelers will create a trip, invite friends, arrange activities around fixed race sessions, track estimated costs, and coordinate packing and reusable checklists. A small, explainable recommendation engine will rank activities against preference, budget, and schedule constraints.
